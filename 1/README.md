# Лабораторная работа №1 — поиск лиц и глаз в реальном времени

Задание: приложение, которое находит лица и глаза на изображении с веб-камеры
в режиме реального времени (каскады Хаара, OpenCV).

Методичка описывает C# / EmguCV — здесь то же самое на Python, так как EmguCV
это лишь .NET-обёртка над OpenCV: те же каскады и те же методы
(`VideoCapture`, `CascadeClassifier.detectMultiScale`).

## Запуск

```bash
uv sync
uv run lab1
```

## Управление

| Клавиша | Действие |
| --- | --- |
| `q`, `Esc` | выход |
| `s` | сохранить снимок в `snapshots/` |
| `e` | поиск глаз вкл/выкл |
| `m` | зеркальное отображение |
| `h` | панель статистики |
| `l` | подписи рамок |
| `p`, пробел | пауза |
| `+` / `-` | `minNeighbors` для лиц |
| `[` / `]` | `scaleFactor` для лиц |
| `c` | выравнивание гистограммы |

## Параметры запуска

```
--camera N              индекс веб-камеры (по умолчанию 0)
--source PATH           изображение или видеофайл вместо камеры
--width / --height      разрешение кадра
--no-mirror             не отражать кадр
--eyeglasses            каскад, устойчивый к очкам
--no-eyes               искать только лица
--detect-every N        детекция раз в N кадров
--scale-factor          scaleFactor для лиц
--min-neighbors         minNeighbors для лиц
--eye-scale-factor      scaleFactor для глаз
--eye-min-neighbors     minNeighbors для глаз
--snapshot-dir DIR      папка для снимков
--output FILE.mp4       запись размеченного видео
--no-display            работа без окна
--max-frames N          остановиться после N кадров
```

Примеры:

```bash
uv run lab1 --eyeglasses         # если вы в очках
uv run lab1 --detect-every 2     # ускорение на слабом железе
uv run lab1 --source photo.jpg   # проверка без камеры
```

## Структура

```
src/lab1/
├── __init__.py   аргументы командной строки, main()
├── app.py        главный цикл: кадр → детекция → отрисовка → клавиши
├── detector.py   каскады Хаара, поиск лиц и глаз
├── render.py     рамки, панель статистики
├── source.py     камера / видеофайл / изображение
└── cascades/     XML-файлы каскадов
```

Лица ищутся по всему кадру, глаза — только внутри найденного лица, в полосе
15–62 % его высоты. Перекрывающиеся рамки отсеиваются по IoU, на лицо остаётся
не больше двух глаз.

Нужен OpenCV 4.x: в OpenCV 5 класс `CascadeClassifier` удалён.
