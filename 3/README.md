# Лабораторная работа №3 — контурный анализ и распознавание текста

Две программы в одном пакете:

* **Часть 1** (`lab3 contours`) — пайплайн обработки изображения с текстом:
  загрузка → оттенки серого → бинаризация → удаление шумов → поиск контуров →
  фильтрация → уравнивание → рамки вокруг контуров, с показом всех
  промежуточных результатов.
* **Часть 2** (`lab3 ocr`) — распознавание печатного текста на русском и
  английском языках через Tesseract OCR с выводом в консоль и на изображение.

## Установка

```bash
uv sync
```

Для части 2 нужен системный Tesseract:

```bash
sudo pacman -S tesseract tesseract-data-rus tesseract-data-eng   # Arch / CachyOS
sudo apt install tesseract-ocr tesseract-ocr-rus tesseract-ocr-eng  # Debian / Ubuntu
```

На Windows путь к программе указывается флагом `--tesseract-cmd`.

## Часть 1: контурный анализ

```bash
uv run lab3 contours samples/text_ru_en.png
```

Открывается окно с сеткой из восьми этапов обработки. Клавиши:

| Клавиша | Действие |
| --- | --- |
| `q`, `Esc` | выход |
| `s` | сохранить снимок в `out/` |
| `0` | сетка всех этапов |
| `1`–`8` | один этап во весь размер |
| `b` | способ бинаризации (Оцу → адаптивная → фиксированная) |
| `+` / `-` | порог фиксированной бинаризации |
| `[` / `]` | размер морфологического ядра |
| `,` / `.` | минимальная площадь контура |
| `n` | число точек при уравнивании |
| `g` | раскраска контуров по группам схожей формы |
| `e` | только внешние контуры / все |

Основные параметры запуска:

```
--binarization otsu|adaptive|fixed   способ бинаризации
--threshold / --block-size / --constant   параметры бинаризации
--kernel-size / --open-iterations / --close-iterations   удаление шумов
--min-area / --max-area-ratio / --min-side   фильтрация контуров
--equalize-points N        длина вектор-контура при уравнивании
--group-threshold          порог схожести форм
--all-contours             искать и вложенные контуры
--stage N                  сразу открыть один этап
--save-stages              сохранить каждый этап отдельным файлом
--no-display               без окна, только сохранение
```

## Часть 2: распознавание текста

```bash
uv run lab3 ocr samples/text_ru_en.png --lang rus+eng
uv run lab3 ocr скан.png --lang rus --text-out out/text.txt
```

Язык выбирается флагом `--lang`: `rus`, `eng` или `rus+eng`. Распознанный текст
печатается в консоль и показывается на выходном изображении: каждое слово
подписывается прямо под своей рамкой, а справа выводится полный текст целиком.

```
--lang rus|eng|rus+eng   язык распознавания
--psm N                  режим сегментации страницы Tesseract
--no-preprocess          без предобработки перед распознаванием
--min-confidence         порог уверенности для слова
--text-out FILE          сохранить распознанный текст в файл
--tesseract-cmd PATH     путь к исполняемому файлу tesseract
--no-display             без окна, только сохранение
```

## Контурный анализ

Контур представляется последовательностью комплексных чисел: точка (x, y)
записывается как x + iy, а элементарные векторы — это разности соседних точек
(`contours.elementary_vectors`). **Уравнивание** (`contours.resample`) приводит
все контуры к одной длине k: точки заново расставляются равномерно по длине
дуги, с линейной интерполяцией между исходными точками. Длина k задаётся
флагом `--equalize-points` (по умолчанию 64) — больше точек даёт точность, но
дороже в расчётах.

Сравнение контуров — нормализованное скалярное произведение и взаимно-
корреляционная функция (`contours.similarity`): считается скалярное
произведение комплексных векторов при всех циклических сдвигах стартовой точки
(через БПФ), берётся максимум модуля и делится на произведение норм. Мера
принимает значение 1 для контуров, отличающихся только поворотом,
масштабом и выбором начальной точки — это проверяется на практике: поворот на
40° и масштаб 2.5× дают ровно 1.0, у разных букв получается около 0.68.
По этой мере одинаковые буквы на изображении объединяются в группы и
раскрашиваются одним цветом (клавиша `g`).
